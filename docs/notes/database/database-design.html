# Database Design

A relational database stores data in tables.

Important concepts:

- Primary key
- Foreign key
- Relationships
- Constraints
- Indexes
- Normalization

Example relationship:

Customer → Orders → Order Items

One customer can have many orders.

One order can have many order items.
